Components Used

This project uses the following hardware components.

---

1. Arduino Uno

Quantity: 1

The Arduino Uno is the main controller of the project. It reads the push button input, generates LED patterns, and sends serial data to the 74HC595 shift register.

Specifications

- Microcontroller: ATmega328P
- Operating Voltage: 5V
- Digital I/O Pins: 14
- Analog Input Pins: 6
- Clock Speed: 16 MHz

---

2. 74HC595 Shift Register IC

Quantity: 1

The 74HC595 is an 8-bit Serial-In Parallel-Out (SIPO) shift register. It expands the number of output pins available on the Arduino by allowing 8 LEDs to be controlled with only three digital pins.

Important Pins

- DS (Pin 14): Serial Data Input
- SH_CP (Pin 11): Shift Clock
- ST_CP (Pin 12): Latch Clock
- OE (Pin 13): Output Enable (Active LOW)
- MR (Pin 10): Master Reset (Active LOW)
- VCC (Pin 16): +5V
- GND (Pin 8): Ground

---

3. LEDs (Light Emitting Diodes)

Quantity: 8

LEDs are used to display different lighting patterns generated by the Arduino through the 74HC595.

Purpose

- Visual indication
- Pattern demonstration
- Output display

---

4. 220 Ω Resistors

Quantity: 8

Each LED is connected through a 220 Ω resistor to limit the current and protect the LED from excessive current.

---

5. Push Button

Quantity: 1

The push button is used to change the LED pattern. It is connected using the Arduino's internal pull-up resistor ("INPUT_PULLUP").

---

6. Breadboard

Quantity: 1

The breadboard provides a solderless platform for building and testing the circuit.

---

7. Jumper Wires

Quantity: As required

Jumper wires are used to make electrical connections between the Arduino, the 74HC595, LEDs, and the push button.

---

8. USB Cable

Quantity: 1

The USB cable powers the Arduino and uploads the program from the computer.
